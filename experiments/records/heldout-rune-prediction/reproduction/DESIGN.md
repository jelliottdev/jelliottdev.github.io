## Proposed choices to freeze

1. **Inputs:** exact source transcription and GP table already pinned by the published MDL record. Source `load_unsolved` uses the first 55 percent-separated segments; retain their exact nonempty boundaries and concatenate to 12,956 symbols. Verify this against the existing source parser before accepting lengths. Do not substitute current website transcription or new pages.
2. **Controls:** independent `random.Random(seed)` per replicate, seeds 3301241024000 through 3301241024999. Execute exact XI soft_pad logic on a 12,956-zero plaintext, suppression 0.83, continuously across all boundaries; split after generation. Store every seed and full stream hash, counts/repeats and aggregate control-array hash. Expected repeat probability is `(1−s)/29+s/29²`, not exactly 86/12,955. Marginal uniformity is in expectation. No suppression refit.
3. **Folds:** nonempty source-page ordinal parity, two folds. Train on one parity and score the other, then swap. Contexts reset at page boundaries in training and test. This intentionally tests cross-page transferable within-page structure; continuous cross-boundary structures remain outside this chosen predictor. All model orders score the same positions, page offsets >=8. Each held-out past rune is a permitted observed conditioning variable; held-out labels never update training counts. No future context, test-based hyperparameter selection or per-page best-order selection.
4. **KT:** fixed order `k` predicts from that exact context with symmetric Dirichlet-1/2 counts across the known 29-symbol alphabet: `(n_symbol+0.5)/(n_context+14.5)`. Unseen contexts give 1/29. Training uses every available in-page transition for that order, not only offset>=8. Report eight aggregate length-weighted held-out bits/rune values and fold/page numerators and denominators; no in-sample entropy substitution.
5. **PPM-C:** static training context counts through maximum order `k`. Start at order k; unseen contexts skip to the next lower order. Exclude symbols observed in unsuccessful higher contexts from lower-order counts. At a context with remaining total N and distinct count D, emit a seen symbol with count/(N+D); an unseen symbol escapes with D/(N+D). If all remaining alphabet symbols have appeared, omit impossible escape and normalize seen counts by N. At order −1 emit uniformly over symbols not excluded. Every probability vector must normalize under a separate scalar checker. This makes escape/exclusion/alphabet details explicit instead of treating the name PPM as a complete specification.
6. **LZMA:** two source views: one rune index per byte, and source base-29 integer packing with its minimal big-endian byte width. Preserve `preset=9 | PRESET_EXTREME`, default XZ container and check. Report exact compressed bytes and bits/original rune against the same 1,000 controls; pin Python/liblzma environment and packing helper parity. No claim that compressed-size changes are frozen-model held-out likelihood. Do not subtract two compressed file sizes and present the difference as exact predictive loss.
7. **Selection:** retain every model/order/arm output. Before targets, root should freeze one whole-family selection correction across predictive, compression and provenance measures, alongside the source marginal 1st-percentile description. Individual minimum-order ranks are not independent tests. The source's claim that an inside-band result confirms OTP/generator class is rejected: a finite model failing to predict does not establish incompressibility, randomness, plaintext absence or cipher-family exclusion.

## Efficient implementation and controls

Build each fold's order-0..8 context-count tables once using sorted base-29 integer context keys and NumPy unique counts. Query all held-out contexts once. Reuse queried counts for all KT orders and all PPM maximum orders; Numba performs the small exclusion/backoff loop. Maximum order-8 code fits int64. A scalar dictionary oracle independently forms contexts, verifies probabilities and held-out losses. No target outputs are needed for benchmarking.

Controls must include deterministic periodic higher-order streams, a stationary random order-2 transition generator shared by training and test, and ordinary filtered-uniform streams. Negative controls include a held-out mapping deliberately different from training, and permutation-disrupted higher-order plants. Verify train-count hashes unchanged by test scoring; change a held-out future symbol and require earlier probabilities unchanged. Include rare/unseen contexts, exact known-alphabet support, full-alphabet contexts, all-identical arrays, short pages, both folds and strict boundary separation. All failures remain in the receipt; do not choose only easy plants after scoring.

Benchmark synthetic full-length instances for both context and LZMA arms, including compilation separately. Project all 1,000 controls plus target before authorizing a full run. Store compact per-stream/model/fold/page losses, control hashes and model-count/checker receipts, not every plaintext or dense all-context table. Root provenance interface: common `uint8` streams `(replicate,12956)`, source lengths list, explicit stream IDs/seeds; no RNG inside metric modules.

The final protocol must bind producer/checker source bytes, model formulas, exact split and shared selection rule, all control outcomes, inputs and runtime projection. Targets remain stopped until independent review explicitly passes.
