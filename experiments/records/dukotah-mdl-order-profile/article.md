# Is LP2's rune order unusually predictable?

A [published analysis](https://github.com/Dukotah/cicada3301/tree/f08b20b632d91209ddbaa747e8e2f23df0c78ba1/liber-primus/analysis/recon/i6_mdl) compared 12,956 unsolved LP2 runes with 40 uniformly random streams. Its strongest result was a lower first-order conditional entropy: **4.7854** versus **4.8125** bits per rune, reported as *z* = −14.6. We reproduced every numeric field by running the unchanged source code.

## What changes when repeats are matched?

![The LP2 first-order entropy is far below independent random controls, but inside the range of controls constructed with the same number of adjacent repeats.](experiments/records/dukotah-mdl-order-profile/order-one-controls.svg)

LP2 has only **86 adjacent equal-rune pairs** in 12,955 transitions. An independently random stream has many more. An ordinary first-order entropy calculation sees this missing transition and can look unusually low without identifying a cipher rule.

We therefore made 1,000 new control streams with **exactly 86** adjacent repeats each. Their mean first-order entropy is **4.7871**, and their middle 95% spans **4.7826–4.7915**. LP2's **4.7854** falls inside; **207 of 1,000** controls are at or below it. Under this specific repeat-matched model, the prominent first-order dip is no longer exceptional.

| Entropy order | LP2 | Repeat-matched mean | LP2 position among 1,000 controls |
| --- | ---: | ---: | ---: |
| No previous rune | 4.8565 | 4.8565 | 480 at or below |
| One previous rune | 4.7854 | 4.7871 | 207 at or below |
| Two previous runes | 3.5228 | 3.5196 | 685 at or below |

The source also tried compressors and phrase counts; their outputs replay exactly. Its order-three through order-five empirical entropies become very small for both LP2 and random controls because nearly all long contexts are seen too few times. Those in-sample values do **not** estimate a held-out entropy rate or establish that the text is generated by a PRNG, a hash chain, or a one-time pad.

## What this covers

The source joins its **55 nonempty LP2 text segments** into one GP29 index stream, including transitions across segment boundaries. We used those same bytes and source alphabet. The new control matches stream length, alphabet size, and total adjacent-repeat count. It does **not** match each page, unigram frequency, word boundaries, or other structure. We designed it *after* seeing the source's first-order anomaly, so it is a diagnostic of that anomaly, not a new discovery test.

The [held-out prediction follow-up](#/experiments/heldout-rune-prediction) now asks whether learned patterns transfer to other pages. It tests 16 fixed predictors, compression, local balance and frequency drift against 1,000 source-filtered controls. None of its 26 measurements crosses the predeclared threshold. That comparison uses a different control rule: repeats are suppressed in expectation, not fixed at exactly 86. It does not identify the cipher or establish randomness.

## Reproduce

The [source replay plan](experiments/records/dukotah-mdl-order-profile/source-plan-as-frozen.json) and [diagnostic plan](experiments/records/dukotah-mdl-order-profile/diagnostic-plan.json) pin their separate scopes. With a checkout of the [pinned revision](https://github.com/Dukotah/cicada3301/tree/f08b20b632d91209ddbaa747e8e2f23df0c78ba1), run from the Liberpedia repository root:

```text
python experiments/records/dukotah-mdl-order-profile/run.py --source-root SOURCE
python experiments/records/dukotah-mdl-order-profile/diagnostic.py --source-root SOURCE --check
python experiments/records/dukotah-mdl-order-profile/check.py --source-root SOURCE
python experiments/records/dukotah-mdl-order-profile/plot.py --check
```

The [source result](experiments/records/dukotah-mdl-order-profile/source-mdl_result.json), [fresh replay](experiments/records/dukotah-mdl-order-profile/replayed-mdl_result.json), and [1,000 diagnostic rows](experiments/records/dukotah-mdl-order-profile/diagnostic-results.json) are retained. The independent checker recalculates every reported entropy from raw rune transitions.
