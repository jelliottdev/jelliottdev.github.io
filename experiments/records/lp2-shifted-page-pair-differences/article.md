# One page as another's key, at every long overlap

**Result.** None of the tested page alignments has unusually concentrated differences against the declared shuffled-page reference. We checked **331,908 alignments**, including **330,582 nonzero offsets** absent from the earlier page-pair record. The largest index of coincidence (IoC) is **0.04721**; **77 of 128** shuffled searches reach at least that value. The plus-one global empirical comparison is **0.605**.

![The strongest actual shifted-page difference lies inside the distribution of shuffled search maxima.](experiments/records/lp2-shifted-page-pair-differences/global-shift-max.svg)

The [pinned source's S1 proposal](https://github.com/Dukotah/cicada3301/blob/f08b20b632d91209ddbaa747e8e2f23df0c78ba1/AUTO_EVOLUTION.md) calls for an all-page, all-offset difference-IoC scan to look for shared keystreams. [The earlier page-pair test](#/experiments/lp2-page-pair-alignment) aligned pages only from their first rune. This record adds shifted alignments within one bounded version of that proposed method.

## The grid

We used the same 55 nonempty LP2-00–55 page transcriptions as the earlier record, including headings. A pair qualifies when both pages have at least 120 runes: **52 pages and 1,326 unordered pairs**. For each pair, we tested every relative integer offset leaving an overlap of at least 120 runes. Pages stay forward, without wrapping or repeating. Each output is the first page's rune indices minus the second page's indices, modulo 29. Reversing the subtraction only relabels its output symbols, leaving IoC unchanged.

This gives 331,908 alignments. The 1,326 zero-offset differences are an explicit overlap with the earlier grid; the remaining 330,582 settings extend its alignment scope. They are settings of the same method, not separate solving ideas. The source's unrestricted all-offset proposal also includes shorter overlaps, which this record does not test.

The highest actual score comes from **LP2-14 minus LP2-35**, pairing positions 0–130 of LP2-14 with positions 140–270 of LP2-35. Its 131-rune output has numerator 804 over denominator 17,030, giving IoC 0.0472108. No reading was selected or proposed from that output.

## A control over the entire search

Each of 128 reference trials independently permutes every complete page, then repeats the **entire** pair-and-offset search using those shared permuted pages. This preserves each page's rune counts and length. It does not preserve every particular overlap window's counts or the page's word and adjacency structure. The reference therefore asks whether the observed maximum is unusual after destroying within-page order while retaining page-level frequencies.

The median shuffled maximum is **0.04750**, slightly above the actual maximum. Seventy-seven of 128 maxima meet or exceed the actual value; `(77 + 1) / (128 + 1) = 0.60465`. Comparing maxima accounts for selecting the strongest alignment from this complete grid. It does not make the permutation model a generative account of the manuscript.

Before the manuscript search, planted page copies at offsets **1, 37 and −53**, with a fixed modular symbol shift, each give the expected constant difference and IoC **1.0**. Shuffling the copied page removes that peak, giving maxima between 0.0392 and 0.0417. These controls establish sensitivity to the declared shifted-copy signal. They do not measure power against two unrelated plaintexts encrypted with a shared random key.

IoC measures symbol concentration, not readable plaintext or every possible form of key reuse. A shared key can cancel between two ciphertexts while leaving a plaintext difference close to uniform. Other offsets with fewer than 120 overlapping runes, reversed pages, repeated or skipped key symbols, other arithmetic and further decoding layers remain open.

## Reproduce

The plan and page hashes were frozen before target scoring. The offline package includes the complete integer count for every observed alignment, all 128 null winners, the planted pages and the input transcript.

```bash
python experiments/records/lp2-shifted-page-pair-differences/run.py --check
python experiments/records/lp2-shifted-page-pair-differences/check.py
python experiments/records/lp2-shifted-page-pair-differences/plot.py --check
```

Python 3 and NumPy are required. The runner repeats the manuscript grid and all 128 reference searches. The independent checker directly recounts every observed alignment, the earlier zero-offset differences, all planted-control alignments and each null-winning slice, then independently recomputes the global comparison. It does not independently exhaust all alignments within every null trial; those are regenerated by the runner.
