Input: archived LP2-00--55 rune streams, headings included, with non-runes removed within each page. Preserve every original page length. The 86 events are overlapping equal-neighbor windows; never create an event across a page edge.

Reference A: condition on 86 events and sample 86 distinct available within-page edge slots uniformly, 10,000 trials with a fixed seed. Page counts may change. Compute expected zero pages independently from exact hypergeometric no-event probabilities using each page's actual edge count.
Reference B: condition on each observed page's event count and sample that many distinct edge slots within the page, 10,000 trials with another fixed seed. This tests within-page placement only; page-level count statistics are fixed by design.
Interpretation: these are placement nulls, not a simulation of plaintext EA, rune frequencies, feedback encryption or overlapping-pair constraints. The measurements were chosen after seeing the 86 events; avoid cipher identification or confirmatory p-values.
