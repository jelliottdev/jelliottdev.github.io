# Keyword-selected columns at the printed word alignment

The 45 source keyword labels specify 43 distinct column orders. Their highest raw dictionary count is 126 of 2,776 visible LP2 word slots, under CIRCUMFERENCE. In a separately frozen **post-target exploratory calibration**, 90 of 128 shared-page shuffled full-search maxima are at least 126. Their range is 116–144 and mean 127.789. The raw target count therefore has an explicit frequency-matched baseline, while the outcome remains **inconclusive about plaintext**.

This is a bounded local-input followup to TheronEagle/liber-primus-research, commit a6c5d13f7591030367daace993c887af20a5e0ab, `experiments/2026-09-23/keyed_columnar_test.py`. The source supplies the exact 45 keyword labels. Each removes repeated letters after their first occurrence, and the resulting letters sort the column reading order alphabetically, with original position as tie break. Original leftmost columns are the longest when a page ends mid-row. For example, CIRCUMFERENCE becomes CIRUMFEN; columns are read in C,E,F,I,M,N,R,U order.

Every original page is processed independently. Slash and line breaks are removed, hyphens define target word slots, and non-runes inside each slot are ignored. After the position permutation, decoded GP labels are divided at those original slot lengths. The fixed English lexicon contains 369,652 entries of at least three ASCII letters. All 2,520 page/keyword rows are retained: 2,475 are nonempty and 45 refer to number-only LP2-50. CICADA/KOAN and TRUTH/MIND specify duplicate column orders, so 45 labels are not 45 independent transforms.

Only two audited source helper definitions execute, without importing or executing module top-level code. An independent implementation inverts an explicit position permutation rather than constructing the source's ragged grid. Both agree on every target output. All 1,125 inverse tests pass across every keyword, short/ragged lengths and a fixed 64-rune known reading. Those tests establish transformation behavior; they are separate from the added scoring controls.

The scoring controls use all 184 output rune indices in the existing Warning decoded trace. Existing punctuation and hyphen boundaries from its page supply 45 known word slots after line wraps are removed. The trace is checked against the existing Atbash mapping. No normalized English reading, new spellings or new lexicon are substituted. The known canonical-GP spelling matches 30 dictionary entries. Each of the 45 keys inverse-transposes that full known reading, and all 45 decoder labels compete under the same dictionary count. The planted true map ranks first in all 45 cases and recovers exact plaintext. Forty-one cases have a unique winning label; the other four tie only with equivalent column-order labels. This is score/rank calibration on one known reading with its known boundaries, not a general-language power bound or proof about the target's hyphen-only word alignment.

For each of 128 null trials, each of 55 nonempty pages is independently rune-order shuffled once, preserving its rune multiset and original target word-slot lengths. The complete 45-label selection is rerun on the same shared shuffled pages. Exact dictionary hits are aggregated across all pages for each key, and one global key maximum is retained per trial. The stored results contain every per-key total and maximum. The seed is 330145. This null was chosen after observing 126, so its 90/128 exceedance count and descriptive add-one fraction 91/129 are **post-target comparisons**, not prospective significance claims. Original paired plans and target result/case bytes remain unchanged.

The source's original absolute-path transcription/dictionary and first 55-block selection are not silently substituted as exact archival inputs. This followup pins 56 original local page files and the existing lexicon. The source's invalid random control—modulo 26 labels applied to one concatenated long word—is excluded. Both the initial pretarget plan and later exploratory calibration plan are retained with exact hashes and clearly different timing.

Vigenere wordlist records change symbol values at fixed positions; these keyword columns move positions while preserving values. Existing row/column routes follow printed geometry. Wulfic's column reversal acts on a fractionated 2N coordinate stream in natural column order; this followup selects alphabetical columns directly on N rune indices. Generic transposition mathematics overlaps, but those records do not execute this exact source grid. The same author's rail-fence method was already covered and is not counted again.

The source code and original MIT license are included with attribution. `run.py` reproduces the immutable original target counts, `calibrate.py` reproduces the exploratory baseline and known-reading scoring controls, `plot_calibration.py` renders the figure, and `check_calibration.py` checks deterministic scientific outputs plus unchanged original bytes.
