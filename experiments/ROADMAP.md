## Ciphertext autokey and F interruptions on LP2-54–55

Reset and skip variants completed as lp2-54-55-autokey-reset and lp2-54-55-autokey-skip. Both maximize at mask 0 / period 13; conditional shuffle estimates p=0.544 and 0.558, with two-mode Bonferroni estimates 1.0. Full reruns and independent checks agree. The full archived streams contain 308 runes and six F occurrences, supporting a 64-subset mask space. The source discussion distinguishes resetting the ciphertext state to F=0 from retaining the previous non-interrupt ciphertext value. In both cases, remove selected interruptions from the measured output, and resume ordinary ciphertext feedback after the next non-interrupt symbol. Plaintext feedback is a different cipher.

Before testing the reported period-13/26 features, specify heading inclusion, page joining, initial state, adjacent-interruption behavior, output-position counting, IoC weighting, period range, and how the mask/period search is repeated in each null trial. Use a small reversible teaching example to catch the persistent-lag bug: with modulus ten, initial state zero and the third plaintext position skipped, 12034 encrypts to 13060. The original script files and plots are only referenced in the supplied text, so a new implementation must be labeled as an explicit new test, not an exact rerun of those unavailable files.
