## Highest-value unfinished work

1. **Word-length comparison corpus.** The manuscript count is reproducible. A pinned twelve-file prefix audit now documents U+16C2 outside the stored GP alphabet in every checked prefix; it is a convenience sample, not a corpus-wide result. The historical reference-corpus pipeline has not been rerun. Freeze the edition list, conversion rules and sampling policy; document any code repair. Distinguish Latin-letter lengths from rune lengths. Do not reuse reported probabilities without reproducing their population and tail definition.
2. **Remaining exclusion claims.** Inspect each closure-register item independently. Prioritize claims that save a concrete bounded search. Keep mathematical impossibility, empirical failure, necessary conditions and untested proposals separate. Preserve counterexamples showing what happens when an assumption is relaxed. C07 now has a fresh all-integer-modulus affine full-palette certificate, independent range checker and partial-palette/noninjective counterexamples in the literal-prime-affine record; C08 page-specific support and nonlinear variants remain separate. The EA running-sum condition (C05) now has an elementary proof, exhaustive finite transition check and inverse-based checker in the doublet guide/scripts; this is a necessary condition, not an exclusion, and does not import the separate English-position model or claim a Lean rerun.
3. **Compass geometry controls.** The current [compass guide](../articles/compass-cipher-tests.html) reproduces an affine-map ambiguity example. It does not reproduce the supplied physical-overlay or restricted-circle reports. Those need original coordinate inputs, tolerances and exact model definitions before being promoted to experiments.
4. **Artwork reuse and source comparisons.** Build on existing image-specific evidence. A shared subject, resemblance or attribution is not a measured reuse relationship. Separate source identification, transformation geometry and unproven cipher relevance. Avoid treating the corrected common tree source as Talbot's oak.
5. **OutGuess execution failures.** The baseline distinguishes reproduced controls, unverified outputs, rejected retrievals and abnormal exits. Another documented executable/build is a useful controlled variant; crashes must not become clean negative results.
6. **27 × 27 totient traversal.** [Selected-route replay](../experiments/records/totient-map-route/article.md) and independent transition calculations are available. Automatic node/path selection remains unspecified. A new variant should freeze those choices and test an unseen continuation; more fits to the supplied route are not held-out evidence.

## How to close a row

Link the authoritative authored page, exact inputs, runnable script, machine-readable results and relevant check. State what remains outside the result. Update the existing topic or experiment family rather than creating a duplicate per parameter or source post. New observations need searchable terms and page links; new computational claims need a reproducible bundle.

The [experiment roadmap](../experiments/ROADMAP.md) retains method-specific proposals and historical test bounds. This document tracks knowledge coverage across guides and experiments; neither is a substitute for the records themselves.
