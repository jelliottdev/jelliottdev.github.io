tools/language-model.json and language-model-data.js contain derived integer trigram statistics,
distributed under CC BY-SA 4.0 with this attribution. Changes: mechanical GP29 orthographic
encoding, additive smoothing and integer log-score quantization. The complete recipe and
source-file hashes are in the payload and scripts/build_language_model.py. No LP text or
FLORES devtest text was used in training. This is not a phonetic language model or evidence
that Liber Primus has any particular plaintext language. Code licensing remains separate.
