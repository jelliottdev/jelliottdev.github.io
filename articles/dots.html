“Dots” can mean several visibly different things in Liber Primus. Large dots separated by wide spaces, small marks between runes, and compact multi-dot clusters should not be treated as one symbol just because a transcription uses similar punctuation for them.

Large separated dots

LP2-33 has three conspicuous black dots between two blocks of text. LP2-39 also has a separated row of three dots. These are useful starting points when someone remembers “the page with dots.” This pair is a set of illustrated examples, not an exhaustive dot inventory of all 75 pages.

Comparing the three-dot spacing

LP2-33 and LP2-39 have differently sized dots, but their adjacent center-distance ratios are close under the same measurement rule. This is a measurable similarity to investigate. It is not an exact geometric identity or a decoded message.

Convert the original JPEG to grayscale, select values strictly below 128, group eight-connected pixels, and retain components of at least 20 pixels. Each window contains exactly three retained components, with no discarded small components. Order them by increasing x-coordinate and label them L, M and R. A center here means the arithmetic mean of selected pixel indices, not a guessed center of an ideal circle.

Distances use the Euclidean formula sqrt((x₂ − x₁)² + (y₂ − y₁)²) on the six-decimal centroids in the exported measurements. The ratios differ by about 0.0001224. Translation, rotation and uniform scaling preserve a distance ratio; stretching horizontal and vertical axes independently does not generally preserve distances. A claimed overlay must state which transformations it allows and how much mismatch it accepts.

For LP2-39, this centroid convention gives 224.5 / 196, not 224 / 196 = 8/7. The half-pixel arises because the first two measured components are 32 pixels wide while the third is 33 pixels wide. Using the left edges instead gives 224 / 196. Edge spacing and center spacing are different quantities; neither should be substituted silently to obtain a preferred fraction.

Reproduce the spacing

Extract reference data and original images into the same folder. With Python and Pillow installed, run:

python scripts/measure_region.py lp2-33 --rect 700 1680 1030 130 --threshold 128 --minimum-area 20 --connectivity 8
python scripts/measure_region.py lp2-39 --rect 1250 1640 520 100 --threshold 128 --minimum-area 20 --connectivity 8

Compare the output with the complete LP2-33 measurement and LP2-39 measurement. These record original-image hashes, pixel areas, bounding boxes, centroids, software version and settings. To calculate the table from either saved JSON file:

import json
from math import dist
from pathlib import Path

for page in ("lp2-33", "lp2-39"):
    report = json.loads(Path(f"data/evidence/{page}-dot-measurement.json").read_text())
    centers = sorted((c["centroid"] for c in report["components"]), key=lambda p: p[0])
    assert len(centers) == 3
    left, right = (dist(a, b) for a, b in zip(centers, centers[1:]))
    print(page, left, right, right / left)

This audit uses one stated threshold and center definition. It has not tested sensitivity across thresholds, matched astronomical coordinates, overlaid dots onto rune positions, or searched other manuscript patterns. Those are separate tests. LP2-39: are the first two dots mirrors?

Yes, within the measured dot rectangles. In the archived LP2-39 JPEG, horizontally reflecting the left dot makes every decoded RGB pixel in its 32 × 33 rectangle equal to the corresponding pixel in the middle dot. Comparing the same rectangles without reflection gives 470 differing pixels out of 1,056, with a maximum channel difference of 11 on the 0–255 scale.

This checks a precise image relationship. It does not establish why the symmetry exists, which drawing or scaling operation produced it, or whether the dots encode an instruction. The comparison covers the rectangles below, not the surrounding JPEG background or the third dot.

Coordinates and measurement rules

Coordinates start at the original image’s upper-left corner. The comparison rectangles are [1282, 1677, 1314, 1710] and [1478, 1677, 1510, 1710], in Pillow’s [left, top, right, bottom] notation; right and bottom are excluded. Both cover 32 columns and 33 rows. These are the bounding rectangles of pixels with grayscale value below 128 in the two display windows, rather than boxes chosen by resizing a screenshot.

Subtracting the first and last pixel coordinates gives 31 and 32, but a count that includes both endpoints gives 32 and 33. This distinction matters when discussing a one-pixel discrepancy. A different intensity cutoff also changes the bounds: counting only pixels at grayscale zero gives 28 × 29 rectangles for these two dots. State the threshold before comparing dimensions.

Reproduce the pixel comparison

Download the original LP2-39 JPEG into an images folder, or use the repository. Install Pillow with python -m pip install Pillow, then run this Python code from the folder containing images. It checks the source file’s SHA-256 before comparing decoded RGB pixels; it does not compare compressed JPEG bytes or thresholded silhouettes.

from pathlib import Path
from hashlib import sha256
from PIL import Image, ImageOps

path = Path("images/lp2-39.jpg")
assert sha256(path.read_bytes()).hexdigest() == (
    "d1b7ea5a6ffb79709753e3565d1d46e05edbe3d82ca70c3ed6065d46b131bd00"
)
im = Image.open(path).convert("RGB")
boxes = [(1282, 1677, 1314, 1710), (1478, 1677, 1510, 1710)]
a, b = [im.crop(box) for box in boxes]
for name, candidate in [("unchanged", a), ("reflected", ImageOps.mirror(a))]:
    pairs = list(zip(candidate.getdata(), b.getdata()))
    changed = sum(left != right for left, right in pairs)
    maximum = max(abs(x-y) for left, right in pairs for x, y in zip(left, right))
    print(name, "different pixels:", changed, "maximum channel difference:", maximum)

Expected output: unchanged different pixels: 470 maximum channel difference: 11, followed by reflected different pixels: 0 maximum channel difference: 0. Verified against the stored original on 20 October 2026. A difference on another decoder should be recorded with its Pillow and JPEG-library versions rather than silently rounded away.

For a proposed astronomical match, start a separate measurement: specify dot centers, the sky positions being compared, allowed rotation/reflection/scale, and tolerance. A mirror match between two dot shapes does not test a constellation match. See image measurement rules and search space and bounds.

Red closing clusters on LP2-22, LP2-32, and LP2-55

These three pages end their black rune text with a narrow red cluster of small square marks. The clusters occupy a similar place in the text layout even though the drawings below them differ: a reclining figure on LP2-22, a soft-edged tree on LP2-32, and a pale tree above a winged figure on LP2-55.

The detail views show unchanged regions of the original JPEGs, at the same display scale. Open a page record and choose Inspect Red dotted mark at the end of the text to see its surrounding text. These are selected examples, not a claim that only these pages have red closing marks.

Calling one a “closing cluster” describes its position. It does not determine whether a key resets there, whether it separates sentences or sections, or whether visually similar clusters represent identical instructions. The LP2-00–02 inventory records punctuation separately from rune shapes. Its measured regions include one-, four-, and thirteen-component groups. The printed mark and the exported character

In the archive notation, a comma represents a three-dot symbol; a period is a clause separator, and an ampersand is a paragraph separator. These are editorial conventions. They are not instructions to insert the prime value of a comma, reset a key, or skip a rune.

One exported character can stand for visually different marks. Before a punctuation-based experiment, identify the exact image regions and the precise sequence you are testing. Otherwise a result may describe the transcriber’s decisions rather than the printed manuscript.
