A numerical proposal combines source values with arithmetic or representational operations to reach a target. Once arbitrary constants, unlimited expression depth and unrestricted reversals are allowed, there is no useful finite search to report as completed.

Major variants

Possible subfamilies include bounded arithmetic trees, digit reversal, base conversion, prime indexing and fixed recurrences. An observed match motivates a hypothesis but does not specify which of these operations were available before it was found.

What a test must specify

List source numbers, allowable constants, operators, bases, maximum expression depth and target set. Define division, concatenation, leading zeros and equivalent expressions. Include every searched variant in the accounting.

How to evaluate a result

Enumerate one finite grammar and report competing targets and duplicate expressions. Use matched control targets or inputs. A method designed around one target should make additional predictions without expanding its operation list.
