The 2013 puzzle reopened with a JPEG telling readers that its first clue was hidden inside the image. The pinned artifact archive preserves that JPEG and a separately saved OutGuess payload. We have now extracted the payload again from the hosted image and compared the bytes.

Recover the hidden instruction

OutGuess with its retrieval mode, outguess -r 232.jpg 232.jpg.asc, extracted 1,459 bytes from the saved JPEG. The fresh output matched the archived payload byte for byte. The extraction diagnostic reported seed 170. The payload starts “Welcome again,” then gives a riddle about a forbidden book and a series of 44 chapter–verse–character coordinates. Two standalone digits, 5 and 0, occur within the coordinate list. The closing 3301 is a sign-off beneath the coordinates, not a third inserted book-code digit.

The payload is a clear-signed OpenPGP message. A fresh GPG check succeeded against the preserved public key, fingerprint 6D854CD7933322A601C3286D181F01E57A35090F. This confirms that the extracted message matches that key; the key is not independently certified to a real-world identity.

From the riddle to the book code

The riddle’s opening identifies a book whose study is forbidden and which should be destroyed after reading. The Liber AL counting guide separates that book identification from the next mechanical step: choose the archived chapter texts, split at numbered verses, remove verse labels and spaces while retaining punctuation, and apply each coordinate. Its full lookup trace includes all 44 references and the two literal digits. A reader can check the source text and each selected character instead of trusting a reported address.

Reproduce the file checks

  1. Download 232.jpg, the saved payload, the public key and the replay script, keeping the repository folder paths if running the script directly.
  2. Run python scripts/replay_2013_opening.py --output opening-2013-check.json for the saved hashes and coordinate count. This does not run OutGuess or GPG.
  3. To repeat the extraction and signature check, run python scripts/replay_2013_opening.py --outguess /path/to/outguess --gpg /path/to/gpg --output opening-2013-fresh.json. The GPG check uses a temporary keyring. The published run report records both fresh checks and the tool hash.
