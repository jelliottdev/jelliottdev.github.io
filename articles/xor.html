Exclusive OR, usually written XOR or ⊕, compares bits. Two equal bits give 0; two different bits give 1. Programming languages commonly use ^ for this operation on integers.

A byte example

00001111   (hex 0f)
00110011   (hex 33)
--------
00111100   (hex 3c)

XOR is not addition with carries and is not alphabet arithmetic modulo 29. It works independently at each bit position.

The three-image chain

The signed bodies from LP1-00, LP1-01, and LP1-02 are first decoded from hexadecimal. XOR their corresponding bytes to reconstruct a signed message. XORing their ASCII hex characters would be a different operation.

Follow the first five bytes

Each row below combines the bytes at one offset in the three decoded streams. Offsets start at zero; all byte values in the table are hexadecimal.

For offset 0, 0x77 ^ 0x17 = 0x60, then 0x60 ^ 0x4d = 0x2d. The output byte 2d is the ASCII hyphen. The first five output bytes therefore form the five hyphens beginning the signed-message header. That recognizable prefix is a useful checkpoint, but it does not verify the remaining bytes or the signature.

How to replicate

Extract the reference-data bundle and run this Python 3 example from its top-level folder. It reads the three preserved message bodies, decodes them, and prints the reconstructed first line. It does not modify the inputs or write an output file.

from pathlib import Path

pages = ("lp1-00", "lp1-01", "lp1-02")
streams = [
    bytes.fromhex(Path(f"exports/steganography/{page}.body.txt").read_text(encoding="ascii"))
    for page in pages
]
a, b, c = streams
assert len(a) == len(b) == len(c) == 991
combined = bytes(x ^ y ^ z for x, y, z in zip(a, b, c))
print(combined.splitlines()[0].decode("ascii"))
assert combined.startswith(b"-----BEGIN PGP SIGNED MESSAGE-----")
# -----BEGIN PGP SIGNED MESSAGE-----

The length check prevents silent truncation by zip. Do not pad, cycle, or trim these documented inputs. This short example checks length and prefix only. For the full recorded input and output hash checks, run python scripts/reproduce_cover_chain.py. Follow the complete recipe for the separate signature verification and transposition.

Useful identities and their limits

A ⊕ A = 0 and A ⊕ 0 = A. Applying the same XOR mask twice recovers the input. The three inputs can be combined in any order because XOR is associative and commutative. Those identities explain the computation; they do not establish why a particular set of manuscript files should be combined.
