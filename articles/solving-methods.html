Start with the kind of operation an idea proposes, then narrow it to a specific rule and test. This map includes decoding methods, ways to search for keys, and diagnostic checks. They overlap: a proposal can combine a route, a numerical key and a reset rule. Combining families adds choices that must be counted.

A family page is not a completed experiment. It describes the approach and how to specify a test. Linked experiment records cover only their stated inputs, variants and bounds. An empty experiment list means a gap in this catalog, not an untouched or promising approach.

Symbol substitutions

Fixed alphabet substitutions
Replace each rune consistently with one other symbol.
Homophonic and many-to-one substitutions
Allow several ciphertext symbols to represent the same plaintext symbol.
Repeating-key and polyalphabetic ciphers
Change the substitution according to position in a repeated key.
Fractionation and coordinate alphabets
Split symbols into coordinates, rearrange the components, then regroup.
Block and matrix transformations
Transform groups of runes together instead of treating each position independently.

Keys, sequences and state

Arithmetic keystreams
Generate shifts from a declared numerical sequence.
Autokey and ciphertext feedback
Use earlier plaintext or ciphertext to update later decoding state.
Seeded generators and unrestricted additive keys
Distinguish short reproducible generators from unrestricted per-position keys.
Running keys from external texts
Convert a specified external text into a stream of key symbols.
Nulls, interruptions and reset rules
Specify which symbols consume output or key state and when state restarts.
Offsets and key alignment
Search starting positions and a bounded set of alignment changes.

Order and selection

Transposition and permutations
Change symbol order while preserving the selected symbols.
Grid layouts, spirals and route ciphers
Choose an explicit layout and traversal through its cells.
Grilles and positional extraction
Select positions using a mask or indexing rule.
Acrostics and boundary-letter extraction
Select initial, final or regularly indexed symbols from defined units.
Word, row, page and section boundaries
Treat boundary choices as explicit input or reset variants.

Book ciphers and coordinate lookups select symbols from a specified source text using explicit coordinate and counting rules. Unlike a running key, a coordinate list points directly into that text.

Numbers and representations

Gematria and rune-sum mappings
Map runes or groups to numerical totals and count competing matches.
Prime indexing and value transforms
Distinguish rune indices, prime values and prime indices before composing operations.
Bounded arithmetic expressions
Declare a finite grammar of operations rather than searching unlimited expressions.
Radix changes and byte encodings
Specify how symbols become digits, integers and bytes.
Bitwise combinations and XOR
Operate on explicitly encoded bits or bytes, with alignment and key rules.
Magic squares and numerical grids
Separate reconstructing a grid from using it as a decoding key.

Physical and digital carriers

File steganography and embedded payloads
Recover data using a specified carrier format, extraction tool and key.
Image transforms and overlays
Measure features under declared processing and alignment choices.
Geometric constructions and navigation
Turn measured positions into reproducible construction and traversal rules.
Audio and frequency encodings
Separate signal processing measurements from a proposed symbol encoding.
Layered decoding and file chains
Specify the order of transformations and verify each intermediate artifact.
Public-key messages and cryptographic artifacts
Work from explicit parameters and historical artifacts rather than assuming the rune text uses the same mechanism.
Hash targets and candidate retrieval
Define exact candidate bytes and compare the specified digest.

Language, clues and search

Language and corpus identification
Compare declared observables with suitable language controls under explicit cipher assumptions.
Known plaintext and crib searches
Use a declared plaintext hypothesis to constrain a defined cipher model.
Automatic search and language scoring
Explore a bounded model with a scorer whose ability and false positives have been checked.
Alternative alphabets and symbolic notations
Define a symbol inventory and an encoding rule before interpreting resemblance.
Literary references and thematic clues
Establish a source relationship, then distinguish interpretation from an executable decoding rule.
AI-assisted candidate interpretation
Treat generated readings as proposals requiring independent, reproducible checks.

Diagnosis and validation

Period and key-length diagnostics
Measure position-dependent patterns with matched null models and correction for searched periods.
Repeats, doublets and word structure
Test structural constraints without automatically converting them into a cipher identification.
Invariants and bounded exclusions
State the assumptions under which an operation preserves or forbids an observed property.
Null models and selection effects
Repeat the whole selection procedure on controls, not just the final attractive candidate.
Source verification and transcription audits
Verify the input and the scope of its authenticity or transcription evidence.

From a family to a test

For example, “try spirals” names a route family. A test must also fix the pages, grid dimensions, padding, starting cell, directions, any added substitution and the criterion for success. Changing one of these choices creates a variant; changing several may create a new experiment family.
