Fixed alphabet substitutions

Replace each rune consistently with one other symbol.

One fixed mapping replaces each input symbol throughout the chosen text. Caesar shifts and Atbash are small special cases; a general substitution can have many more choices. On a 29-symbol alphabet, an affine map uses y = ax + b modulo 29 with nonzero a. A permutation preserves symbol counts up to relabeling and preserves the pattern of equal symbols.

Major variants

Variants include Caesar, Atbash, affine maps, arbitrary alphabet permutations and keyed alphabets. A different map for each position belongs to a polyalphabetic or state-dependent family instead.

How much of the family did a search cover?

	Mapping class on indices 0–28	Number of maps	Assumptions
	Caesar: y = x + b mod 29	29	One fixed alphabet order; all offsets, including zero.
	Atbash: y = 28 − x	1	The same fixed alphabet order.
	Affine: y = ax + b mod 29	28 × 29 = 812	Nonzero multiplier a and any offset b.
	Arbitrary alphabet permutation	29! ≈ 8.84 × 10³⁰	Each input has a distinct output.

These classes overlap: Caesar maps and Atbash are already affine maps. Searching all 812 affine maps does not search all permutations. A keyed-alphabet method explores the maps produced by its keyword list and construction rule; different keywords may produce the same map. Report both attempted keys and distinct resulting mappings.

Because 29 is prime, every nonzero multiplier has an inverse modulo 29. Allowing a = 0 would collapse every input to b, so it would no longer be a permutation. See modular arithmetic.

Check repeated symbols before searching keys

Give the first distinct symbol label A, the next new symbol B, and so on. The invented input 3, 8, 3, 4 has pattern A B A C. A fixed one-to-one substitution must preserve that exact pattern at aligned positions.

	Proposed output	Pattern	Compatible with a permutation?
	7, 2, 7, 5	A B A C	Yes, at these positions. It leaves most of the alphabet unspecified.
	7, 2, 5, 6	A B C D	No. Input 3 would need two different outputs.
	7, 7, 7, 5	A A A B	No. Distinct inputs 3 and 8 would map to the same output.

Assigning input 3 two different outputs contradicts any fixed function. Merging inputs 3 and 8 specifically violates the one-to-one requirement; a many-to-one decoding map could merge the two input symbols. A pattern match is necessary for a permutation, but it is not evidence that the candidate phrase is correct.

Perform this comparison in the same symbol units on both sides. A rune transliterated as TH is one symbol, not two letters. A proposed English phrase needs a declared conversion into the rune alphabet before its repetition pattern can be compared. Do not silently change word breaks or omit symbols to make the patterns agree.

Recover an affine candidate from two assignments

Suppose two distinct input indices are proposed to decode as 3 → 11 and 8 → 21. Subtracting the affine equations gives 5a = 10 mod 29, hence a = 2 and then b = 5. This candidate sends 3, 8, 3, 4 to 11, 21, 11, 13.

The inverse is x = 15(y − 5) mod 29, because 2 × 15 = 1 mod 29. Apply it to the complete output to check recovery. A third proposed assignment must agree with the same a and b; choosing fresh parameters for each word changes the model.

Two distinct input-to-output assignments determine at most one invertible affine map on this alphabet. They still leave 27! general permutations when both output indices are distinct. That difference is why a failed affine crib test must not be described as excluding all fixed substitutions. The constraint-solving guide explains how to record these assumptions and check alternative assignments.

Which statistics can distinguish candidates?

A permutation relabels symbol counts without changing their sorted values. Whole-stream IoC and single-symbol entropy therefore remain identical across all candidate permutations of the same input. Neither can rank those keys.

A language score tied to particular symbols or sequences can differ across keys, but depends on its language, rune conversion and training text. A good score still needs a complete reading, an independently reproducible key and evaluation on material not used to select it. See cipher invariants and language identification.

What a test must specify

Fix the alphabet order, direction of the map, treatment of non-rune marks, text span and permitted mapping class. A search over affine maps is not a search over all substitutions.

How to evaluate a result

The constraint-solving example shows how a repeated input can reject an incompatible crib, and why a compatible short crib can leave several complete keys.

Use synthetic encodings with known keys to test recovery. Check preserved equality patterns before language scoring. Evaluate full candidates and untouched text, rather than selecting isolated plausible words.
