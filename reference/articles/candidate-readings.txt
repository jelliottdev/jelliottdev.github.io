Evaluating candidate readings

Distinguish a known-opening match, a language ranking and a complete reading, and interpret the limits of each test.

A script can generate thousands of candidate readings without telling us whether any is a decryption. To interpret its result, first ask what the script was instructed to recognize. Matching a fixed beginning, receiving a high language score and reproducing a complete reading are different achievements.

For the other half of the question—exactly which possibilities produced these candidates—see search space and bounds.

What an opening test answers

Several experiments in this wiki compare the first twelve output rune indices with nine beginnings taken from known readings. The numerical-sequence family, for example, uses Warning, Welcome, Some Wisdom, the first koan, Loss of Divinity, the second koan, Instruction, LP2-56 and LP2-57. These are exact vectors stored in each plan, with hashes identifying their source traces.

This asks a useful, limited question: does this declared transformation produce one of those particular beginnings at the start of this input? It does not ask whether the output contains any possible English sentence. There is no established requirement that an unsolved page must repeat a known opening.

The comparison is in runes, not twelve Latin characters. A rune label such as TH can contain more than one letter. See rune counts and character counts before attempting to reproduce the comparison from a displayed transliteration.

A match can be too narrow for the conclusion

The following invented examples use ordinary characters so the distinction is visible. Suppose the test accepts any string beginning with THE , while the complete reference is THE DOOR IS OPEN. None of these strings is a manuscript result.

	Candidate	Opening test	What remains unknown

	THE DOOR IS OPEN	Passes	This also equals the supplied full reference, but that requires a separate comparison.

	THE XXXX XX XXXX	Passes	The opening test says nothing about the remainder.

	PLEASE OPEN THE DOOR	Fails	The readable sentence begins differently. This test was not designed to recognize it.


The second row is a correct positive result for the stated prefix test. The error would be reporting it as a complete decryption. Likewise, the third row is a correct negative for that prefix; the error would be treating it as proof that the text cannot be readable.

Read the actual result with its scope


Prime-minus-one shifts
3190 configurations on 55 nonempty LP2 pages produced no matches to the nine declared beginnings. The tested offsets, directions and uninterrupted advancement are part of that result.

Fibonacci shifts
3190 configurations produced 1540 distinct full page outputs. The repeated configurations do not add different candidates; neither count is a count of independent statistical observations.

Row and column reading routes
Sixteen declared routes per nonempty page produced no matches to the same nine beginnings. This does not cover arbitrary transpositions or a second cipher applied after rearrangement.


A precise report says “no declared opening matched under these rules.” It should not shorten this to “Fibonacci does not work” or “transposition was ruled out.” Conversely, keeping a method open is not evidence in its favor: it identifies what the recorded test has not settled.

What full-output language tests found

The full-output row and column test checks the same sixteen routes as the opening test above, but scores the complete output instead of requiring a known beginning. It found no deciphered passage. Its strongest output comes from LP2-22 and begins WRRJJTMUXW…; 16 of 256 shuffled whole-search comparisons scored at least as highly.

The search covers 55 rune-bearing LP2 pages using archived rows and left-aligned ordinal columns, with a fixed English four-letter score on GP labels. It does not test physical image columns, diagonals, an additional cipher layer or other languages. The shuffled comparison includes selecting the best of all sixteen routes on every page; it does not account for choosing this family after considering other ideas. The chance-comparison guide explains that distinction.

The highest-scoring candidate always exists when a finite nonempty set has numeric scores. Its rank alone does not tell us that the candidate is meaningful. Publish the competing outputs and score differences, rather than showing only the winner.

The eight-language scorer controls now test a fixed English threshold on known text and letter shuffles. The planted decoder controls separately compare exact rune recovery with score acceptance: value rewriting often leaves a high-scoring but incorrect sequence. A separate search-maximum control now checks complete nested dictionaries through 256 keys; it does not calibrate larger or adaptive searches. The fixed-opening searches retain their original acceptance rule and results.

If a candidate looks promising

Cribs and text reserved for checking a prediction

A crib is an assumed piece of plaintext at a specified position. For example, assuming that the first three decoded rune indices spell a particular word supplies a constraint on the key. The spelling, rune encoding and location are part of that assumption. A word that merely sounds plausible is not independently known plaintext.

The withheld continuation is text that you did not use to choose the candidate. Freeze the key and decoding rules before inspecting it. Then ask whether the same rule predicts the continuation without new exceptions. If you use the continuation to change the key, choose a different path or repair the spelling, it has become part of development rather than an untouched check.

The known-crib seed controls make this distinction measurable. At two opening runes, the four searches containing their planted generator and seed retain 4, 6, 11 and 8 candidates. Only the true generating pair in each search predicts the complete remaining passage. Other controls obtain prefix matches even with a wrong generator or an incorrect crib. These are synthetic fixtures with known answers, not new readings of the unsolved pages.

For an unsolved passage, the continuation has no known answer to compare against. Record what would count as corroboration before inspecting it: exact additional text specified by an independent source, reproducible constraints, or a separately justified decoding result. Readability judged after trying many alternatives remains a selection process; a longer attractive phrase alone does not provide the same check as exact recovery of withheld known text.

Preserve the complete candidate

Save the complete output and the exact settings before making interpretive changes. Check the transcription against the image, then apply the same declared rule to the rest of the stated input. Mark every exception, skipped rune and inserted word. A short attractive phrase should not hide unexplained text elsewhere.

Distinguish a control from a prediction. Recovering a known reading can show that an implementation handles a documented method. If you designed a rule around that reading, recovering it does not independently establish the rule on an unsolved page. A useful follow-up specifies what additional text or feature the rule should explain before inspecting that result.

When changing a criterion or boundary rule after seeing an output, preserve the original record and describe the change in a related experiment. The reproducibility guide explains how to retain the inputs, commands and limits. Have we tried it? keeps those separate records together as a family without turning a narrow negative result into a universal verdict.


Before searching keys for a proposed word, check whether its rune repetitions fit the assumed cipher. The worked crib-pattern check gives an exact compatibility test for fixed one-to-one substitutions, including why separately plausible words can conflict under one shared mapping.


For a worked numerical example, see key alignment, skip limits and beam search. It shows how one rejected key slot changes the subsequent decoding and distinguishes a prohibited path from one discarded by scoring.
