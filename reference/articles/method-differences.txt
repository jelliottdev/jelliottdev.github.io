Differential and cumulative decoding

Transform changes between values with declared direction, lag, modulus and initial conditions.

Differential decoding works with changes between values rather than the values themselves. For a rune stream represented by indices 0 through 28, one possible rule is d[i] = (x[i] − x[i−1]) mod 29. This is a precise transformation, but it is only one member of the family. Choosing subtraction after seeing an attractive result does not establish that it was intended.

A small reversible example

This invented sequence illustrates arithmetic only; it is not a manuscript reading. Preserve the first value as an initial condition, then take differences between consecutive values.

	Position	Input index	Operation	Stored value
	0	27	Keep initial value	27
	1	1	(1 − 27) mod 29	3
	2	4	(4 − 1) mod 29	3
	3	3	(3 − 4) mod 29	28

The differences are 3, 3 and 28. Starting from 27 and cumulatively adding them modulo 29 recovers 27, 1, 4, 3. Without the initial value, there are 29 possible reconstructions differing by a constant shift. A difference stream alone has lost that information.

Variants and boundaries

Variants include signed or absolute differences, larger lags, differences of prime values, cumulative sums, repeated differencing and two-dimensional neighbor rules. Absolute differences discard direction and are generally not invertible without extra information. A page-by-page restart also differs from carrying state across a page boundary.

Absolute difference is a different operation

For the first pair in the example, ordinary integer subtraction gives 1 − 27 = −26, its absolute value is 26, and its residue modulo 29 is 3. These are three different values. Specify the order of absolute value and modular reduction; taking an absolute value after reducing to 0–28 does nothing.

Even retaining the initial value does not generally make absolute differences reversible. The ordinary integer sequences 10, 13, 16 and 10, 13, 10 both start at 10 and have absolute differences 3, 3. Both lie within 0–28. Choosing the signs from a desired plaintext introduces choices that the difference values did not supply.

For a fixed start and m positive absolute differences, choosing a sign at every step gives at most 2^m paths before enforcing the allowed value range. A zero difference has only one distinct next value. Range restrictions can eliminate paths, so the upper bound is not necessarily the number of valid reconstructions.

A larger lag creates separate chains

For lag two, define d[i] = (x[i] − x[i−2]) mod 29 for positions i ≥ 2. The even positions form one chain and the odd positions another. Each needs its own initial value.

	Input	Seeds retained	Lag-two differences	Reconstruction
	27, 1, 4, 3	x[0] = 27, x[1] = 1	6, 2	x[2] = 27 + 6 mod 29 = 4; x[3] = 1 + 2 = 3

For a fixed lag k with 1 ≤ k < N, an N-symbol stream gives N − k differences. Without the first k values there are exactly 29^k reconstructions over the full 29-symbol alphabet. Each choice of seeds determines one stream. Additional cribs or restrictions can reduce that count, but those are extra assumptions.

Resets discard cross-boundary differences

Split the original example into [27, 1] | [4, 3]. Continuous lag-one differencing gives 3, 3, 28. Resetting at the boundary and storing only within-part differences gives [3] | [28]: the middle 3, which linked the two parts, is gone.

For N symbols split into R nonempty parts, within-part lag-one differencing produces N − R differences. Reversing it requires one initial value per part. If those initial values are unknown and unrestricted, there are 29^R reconstructions. If the method stores the original first symbol of every part, the full representation still has N values and is reversible; label the seeds so they are not mistaken for differences.

Repeated differencing needs more initial information

The first differences of 27, 1, 4, 3 are 3, 3, 28. Differencing again gives 0, 25. To invert both steps, retain the first original value, 27, and the first first-difference value, 3. The two second differences alone leave 29² = 841 possible four-symbol inputs.

A smooth or simple higher-difference sequence is therefore not a unique decoding. State the number of differencing passes and the initial conditions used at each pass. Cumulative summation is an inverse only for the matching difference definition and boundary policy.

What a test must specify

Fix the representation, modulus, subtraction direction, lag, traversal and initial conditions. State whether each word, row, page or section resets the calculation. If repeated differences are allowed, bound their depth. Preserve a source-position trace and report any values discarded at boundaries.

What would support the rule?

For a reversible variant, verify the inverse on complete inputs. If a rule is chosen on one segment, test an untouched continuation with the same initial-state policy. Compare the complete selection procedure with controls. A repeated difference or a short word is an observation, not by itself a cipher identification.
