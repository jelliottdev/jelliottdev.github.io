Method and reproduction
Vigenère: worked explanation. The recorded transformation is p = (c − key[j mod key length]) mod 29, using zero-based positions in the 29-rune alphabet.
Key indices: 23, 10, 1, 10, 9, 10, 16, 26.
Start at sequence position 0. Carry the sequence across the listed page boundaries. Non-rune characters do not consume key positions.
Copy these zero-based rune ordinals without advancing the sequence: 48, 74, 84, 132, 159, 160, 250, 421, 443, 465, 514. See interruptions and counting conventions; these recorded positions are not a universal rule for other pages.
python scripts/reproduce_reading.py welcome
python scripts/reproduce_reading.py welcome --trace
Run with Python 3 from the extracted reference-data bundle or a full repository checkout. The script checks its result against the shipped literal controls before printing. It uses no network or AI requests. Read the script · Exact parameters and provenance.
Inspect the arithmetic
Download the per-rune trace (CSV). Open it in a spreadsheet to follow each input rune through to its output. Each row identifies its manuscript page and zero-based rune position; key counters show when the sequence advances or pauses. Blank key fields mean that the method does not use that counter.
