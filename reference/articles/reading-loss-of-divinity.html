Method and reproduction

Direct reading: worked explanation. The recorded transformation is p = c, using zero-based positions in the 29-rune alphabet.

python scripts/reproduce_reading.py loss-of-divinity
python scripts/reproduce_reading.py loss-of-divinity --trace

Run with Python 3 from the extracted reference-data bundle or a full repository checkout. The script checks its result against the shipped literal controls before printing. It uses no network or AI requests. Read the script · Exact parameters and provenance.

Inspect the arithmetic

Download the per-rune trace (CSV). Open it in a spreadsheet to follow each input rune through to its output. Each row identifies its manuscript page and zero-based rune position; key counters show when the sequence advances or pauses. Blank key fields mean that the method does not use that counter.

How to read the CSV columns · Source hashes and exact parameters (JSON). These files reproduce the known reading above; they do not test a new solution.

THE LOSS OF DIVINITY THE CIRCUMFERENCE PRACTICES THREE BEHAVIORS WHICH CAUSE THE LOSS OF DIVINITY CONSUMPTION WE CONSUME TOO MUCH BECAUSE WE BELIEVE THE FOLLOWING TWO ERRORS WITHIN THE DECEPTION 1 WE DO NOT HAVE ENOUGH, OR THERE IS NOT ENOUGH 2 WE HAVE WHAT WE HAVE NOW BY LUCK; AND WE WILL NOT BE STRONG ENOUGH LATER TO OBTAIN WHAT WE NEED MOST THINGS ARE NOT WORTH CONSUMING PRESERVATION WE PRESERVE THINGS BECAUSE WE BELIEVE WE ARE WEAK IF WE LOSE THEM WE WILL NOT BE STRONG ENOUGH TO GAIN THEM AGAIN THIS IS THE DECEPTION MOST THINGS ARE NOT WORTH PRESERVING ADHERENCE WE FOLLOW DOGMA SO THAT WE CAN BELONG AND BE RIGHT; OR WE FOLLOW REASON SO WE CAN BELONG AND BE RIGHT THERE IS NOTHING TO BE RIGHT ABOUT; TO BELONG IS DEATH IT IS THE BEHAVIORS OF CONSUMPTION, PRESERVATION AND ADHERENCE THAT HAVE US LOSE OUR PRIMALITY, AND THUS OUR DIVINITY SOME WISDOM AMASS GREAT WEALTH NEVER BECOME ATTACHED TO WHAT YOU OWN BE PREPARED TO DESTROY ALL THAT YOU OWN AN INSTRUCTION PROGRAM YOUR MIND PROGRAM REALITY
