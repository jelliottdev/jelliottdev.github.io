Two mappings, two jobs

The alphabet has 29 symbols. Its zero-based indices run from 0 to 28. Its prime values are the first 29 primes, from 2 to 109. F has index 0 and prime value 2; U has index 1 and prime value 3; TH has index 2 and prime value 5.

Known substitution ciphers use indices modulo 29. A Gematria Primus sum adds the prime values. Replacing one operation with the other changes the hypothesis.

See prime values and prime indices for the indexing convention and larger-number examples.

Index, ordinal position, and prime value

The first rune has index zero, but it uses the first prime. If pn denotes the nth prime, the rune at alphabet index i has value p_(i + 1). The extra one converts zero-based alphabet indexing into one-based prime numbering.

Rune / labelAlphabet indexPrime ordinalPrime value
ᚠ · F01st2
ᚢ · U12nd3
ᚦ · TH23rd5
ᛠ · EA2829th109

For example, subtracting the key index 1 from the rune TH gives (2 − 1) mod 29 = 1, which is U. Subtracting one from TH’s prime value instead gives 4, which is neither its new alphabet index under that rule nor a rune’s prime value. The operation must say which column it uses.

Alphabet, palette and observed support

The alphabet is the complete set of 29 rune symbols. In a prime-value experiment, the palette is the corresponding set of 29 allowed prime numbers. A page’s support is the subset actually present on that page. Repeating a rune changes its frequency but does not add another member to the support.

ObjectExampleWhat it retains
Rune sequenceF–U–F–THOrder and repetition: four symbols
Rune support{F, U, TH}Which symbols occur: three types
Prime-value support{2, 3, 5}The same three types represented by their prime values
FrequenciesF: 2, U: 1, TH: 1How often each type occurs, without its positions

A claim about a full alphabet can be stronger than a claim about a page’s support. For example, an output rule may fail on a rune that never occurs on the tested page. The page-support experiment measures this distinction: the archived LP2-55 stream uses 25 rune types, whereas 53 other nonempty LP2-00–55 pages use all 29. This is a property of the stated transcription, not a claim about what the unseen plaintext contains.

Collisions, injectivity and permutations

A collision occurs when two different inputs give the same output. A map is injective on a chosen input set if no such collision occurs there. You must name that input set: a rule can be injective on the observed runes but fail on the whole alphabet.

Rule and input setOutputsConclusion
Send both F and U to FF → F; U → FCollision: not injective
Swap F and U on {F, U}F → U; U → FInjective; the output set equals the input set
Send F to T and fix U, on {F, U}F → T; U → UInjective, but the output set {T, U} differs from the input set

A permutation of a finite set rearranges that same set: every member appears exactly once among the outputs. The swap above is a permutation of {F, U}; the third rule is not. A bijection pairs every member of a specified input set with exactly one distinct member of a specified output set, covering both sets. Thus the third rule is a bijection from {F, U} to {T, U}, even though it is not a permutation of {F, U}.

For the full 29-prime palette, requiring 29 distinct outputs all inside that same 29-element set forces a permutation. For a page containing only 25 prime values, requiring 25 distinct outputs inside the full palette does not force the output subset to equal the input subset. This is the difference between the full-palette affine baseline and its page-specific variant.

Why a missing rune can matter

On LP2-55, one allowed affine rule changes F to T and fixes every observed odd prime. T is absent from the input, so no observed input already maps to T. Extend that same rule to the full alphabet and T maps to itself too: F → T and T → T now collide. A test confined to the page and a test covering the full alphabet therefore reach different conclusions without contradicting each other.

Neither injectivity nor a lack of collisions proves a decryption. These properties only describe what the rule does to the specified symbols. To judge a proposed reading, also examine the key, boundaries, validation criteria and evidence beyond the text used to choose the rule; see evaluating candidate readings.

Count symbols, not Latin characters

TH, EO, NG and other multi-letter labels each denote a single rune. U/V and C/K renderings also require the stated convention. Work from runes when computing sums and offsets.

Reproduce a small example

For F–U–TH, the indices are [0, 1, 2] and the prime sum is 2 + 3 + 5 = 10. Atbash transforms the indices to [28, 27, 26]; it does not reverse the digits of the sum.

Read the mappings from the reference data

From the extracted reference-data bundle or repository, save this as a Python 3 file and run it. It uses the alphabet stored in data/index.json, rather than a separately typed list of prime values.

import json
from pathlib import Path

alphabet = json.loads(Path("data/index.json").read_text(encoding="utf-8"))["alphabet"]
by_rune = {entry["rune"]: entry for entry in alphabet}
by_index = {entry["index"]: entry for entry in alphabet}
source = "ᚠᚢᚦ"
entries = [by_rune[rune] for rune in source]
indices = [entry["index"] for entry in entries]
prime_values = [entry["prime"] for entry in entries]
output = [by_index[28 - index]["latin"] for index in indices]

print("Indices:", indices)
print("Prime values:", prime_values)
print("Prime sum:", sum(prime_values))
print("Atbash labels:", "-".join(output))

Expected output:

Indices: [0, 1, 2]
Prime values: [2, 3, 5]
Prime sum: 10
Atbash labels: EA-IA-Y

The same three input runes support two separate calculations. The sum combines their prime values into one number; Atbash transforms each alphabet index and keeps three output symbols. Adding the input indices would give 3, a third calculation that should not be reported as the Gematria Primus sum.

This example accepts only the three runes shown. It deliberately does not strip punctuation or guess Latin spellings. When extending it to a manuscript passage, declare the text layer and separator rules first; use the prime-sum reproduction guide for complete known-reading examples.
