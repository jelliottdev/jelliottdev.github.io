“Has this been ruled out?” needs a model, not only a method name. A proof about a direct polynomial output does not rule out a polynomial key mixed with unknown plaintext. A frequency result for independent uniform keys does not cover dependent keys. This register records ten useful constraints with the assumption that makes each one apply and the change that would reopen the question.

These are a curated subset of the published evidence, not a claim that all previous attempts have been found. Read a linked experiment record for its exact inputs, scripts and review status. The machine-readable register (JSON) has the same distinctions for external tools and AI readers.

How to use a constraint

Write down your proposed output representation, page boundaries, clock, reset rule and any extra layer. Match those choices against the assumptions below. If they match, the linked result can save a repeat test or tell you which score cannot distinguish candidates. If one material assumption changes, document the new variant instead of either ignoring the earlier result or claiming that the whole family has failed.

Exact contradictions

A stream that forbids adjacent repeats

The archived LP2-00–55 rune streams contain 86 doublets across 12,901 within-page adjacent pairs. A proposed direct output rule that guarantees zero equal neighbors at every one of those positions cannot produce these same streams. The contradiction disappears if a later operation can insert, move or create repeats, if the rule has exceptions, or if the input layer changes. Inspect the count and boundary rule.

Invariants: scores a search cannot improve

Fixed one-to-one rune substitution

A single injective map preserves whether each adjacent pair is equal. It can rename the 86 doublets but cannot remove or create them without another operation. This does not reject a fixed substitution of unknown plaintext that already has the matching equality pattern. A many-to-one map, changing key or transposition changes the argument. See the proof and measurement table.

Pure routes and whole-stream IoC

Rearranging the same runes preserves their frequencies and whole-stream IoC. Therefore, choosing the “best” pure route by that one score cannot work: every route ties. Order-sensitive language scores or IoC on selected columns may differ, so no route is excluded. The invariants guide separates those measurements.

Periodic one-to-one maps

Once period and phase clock are fixed, a one-to-one map within each phase preserves equality pairs and IoC inside that phase. Searching phase keys cannot raise this score. Whole-stream IoC can still change because it also counts cross-phase pairs; a different period or skip rule changes the tested grouping. This is a scoring shortcut, not an exclusion of periodic substitution. Work through the phase example.

Statistical evidence, not impossibility

Independent uniform additive keys

In the specified model, every position receives an independent uniform additive key modulo 29. It predicts about 444.86 doublets over the fixed 12,901 within-page pairs; the observed count is 86. The conditional lower-tail probability is about 1.0708 × 10⁻⁹⁸. That is strong disagreement with this model, not a proof that random keys or arithmetic ciphers are impossible. Nonuniform, dependent or filtered keys require their own test. Read the full experiment.

Bounded exclusions: check the representation

Fixed affine maps of the full prime palette

The full-palette audit finds no nonidentity fixed affine permutation of all 29 literal Gematria Primus prime values for the declared moduli above 109. That statement does not cover rune-index arithmetic or a page using only a subset of the palette. In fact, the page-support audit finds two extra affine maps on LP2-55’s restricted support. Read the full-palette and per-page scopes together before reusing either result.

Fixed quadratic maps of the full palette

The quadratic audit likewise finds no nonidentity permutation under its complete-palette, degree-at-most-two rule. Higher-degree maps, partial supports and changing keys remain outside it.

Direct polynomial output streams

For the declared fixed signed-stride clocks and two output representations, the degree-one-through-eight check excludes a direct polynomial stream on each of the 55 nonempty LP2-00–55 pages. It does not test a polynomial key added to unknown plaintext, irregular clocks, resets or degree nine and above.

Unit-stride divisor labels

All 55 nonempty page streams fail the necessary condition for the declared fixed divisor-label rule on consecutive positions. The result also bounds general coprime strides. It does not reject every position or prime-based method: irregular clocks, noncoprime strides, time-varying labels and output layers remain separate proposals.

Necessary conditions, not rejected methods

Deterministic word resets

Among the selected archived ciphertext units, the word-repeat audit finds no exact repeated pair. If the same deterministic function starts each unit with the same key and reset state, equal plaintext units would have equal ciphertext; therefore the corresponding selected plaintext units must be distinct. A related shared-symbol-map-and-shuffle model has no anagram pair of length five or more under its selected-token policy. Neither observation proves that plaintext must repeat, and changing keys, padding or boundaries changes the model.

Where to go when your idea differs

Use search space and bounds to state the altered choices and the experiment series to find related work. Preserve the earlier result as a control. For example, a page-specific prime map should be compared with the full-palette and page-support audits; a punctuation-sensitive clock needs the archived-versus-reviewed text baseline. The register is for narrowing a test, not declaring an unexplored idea dead by association.
