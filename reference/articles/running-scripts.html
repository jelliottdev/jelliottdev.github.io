Running the reproduction scripts

Set up the repository, verify a known reading, understand a rune-by-rune trace, and diagnose common errors.

Reproducing a reading means starting with the manuscript's rune text, applying the documented cipher, and checking that you get the same result. It is a useful first step into solving: you can see how a method works before changing it or trying it on an unsolved page.

This walkthrough uses LP1-01, the warning. Its Atbash cipher reverses the rune alphabet, so you can follow the calculation by hand as well as run it in Python. By the end, you will have decoded the page, checked your result, and inspected the first two runes step by step.

1. Download and open the files

Download the reference-data ZIP and extract it into an empty folder. Open that folder: you should see directories named scripts, text and data. Keep them together. The script supplies the instructions; the other folders supply the manuscript text, cipher settings and known readings it needs.

Open START-HERE.txt in the extracted folder for a task-by-task command list: decode a known reading, find a phrase, measure rune distributions, locate repeats, or replay an earlier puzzle chain. You can also read those instructions before downloading.

Open a terminal in this folder. A terminal is the window where you type the commands below. On Windows, you can use File Explorer's Open in Terminal command. If you navigate there with cd, put quotation marks around a folder path that contains spaces.

The reference-data ZIP is enough for this walkthrough. If you want to edit the site or work with draft experiments, get the complete repository instead using Code → Download ZIP. Readers who already use Git can clone it:

git clone https://github.com/jelliottdev/jelliottdev.github.io.git
cd jelliottdev.github.io

2. Check Python

You need Python 3. On Windows, try py --version; on macOS or Linux, try python3 --version. If neither command is available, install Python from the official Python downloads or your operating system’s package manager, then reopen your terminal. A command that prints a Python 2 version is not suitable.

TerminalRun the warning example
Windows PowerShellpy scripts/reproduce_reading.py warning
macOS / Linuxpython3 scripts/reproduce_reading.py warning
If python already selects Python 3python scripts/reproduce_reading.py warning

The wiki’s other recipes use python as shorthand. Substitute the command that worked on your machine; the script path and arguments stay the same. The calculation runs on your computer; it does not use the site's AI assistant.

3. Decode the warning and check the result

Check the extracted files first

Before decoding, check that the extracted files match the bundle’s recorded sizes and hashes. Run this from the folder containing scripts, text and data, using the Python command that worked above:

python scripts/verify_bundle.py REFERENCE-DATA-CONTENTS.json

A successful check reports a file count followed by 0 problems. The count can change as the wiki grows. Missing or changed files are listed with FAIL:, and the command exits unsuccessfully. The checker reads files without modifying them; files you add yourself are outside its manifest and are not checked.

This is a check against the included manifest, not independent proof of who created it. You can also compare the ZIP itself with the download catalogue. See bundle verification for the distinction between checking the archive and checking its contents.

Run the known control

Run the warning command from the table above. In the examples that follow, python means whichever Python 3 command worked on your machine.

python scripts/reproduce_reading.py warning

The script reads LP1-01, applies Atbash, and compares its output with the stored reading. It then prints === LP1-01 === followed by the decoded text. Open the complete warning reading beside it to compare the output with the explanation.

The spelling may look unusual. The output uses literal rune labels, which preserve distinctions that ordinary English can hide. Keep those spellings when checking the result; the guide also provides contextual English to help you read the message.

Once this example works, check the other known readings:

python scripts/reproduce_reading.py --list
python scripts/reproduce_reading.py --check-all

--list shows the nine named sections available to the script. --check-all decodes them and should finish with:

PASS: 17 literal page readings match the published controls exactly.

A control is an example whose expected result is already known. Matching it helps check that the implementation and inputs work together. There are nine sections but 17 pages because some sections span several images. This command checks those known readings; it does not attempt the unsolved pages or extract hidden image content.

4. Read a rune-by-rune trace

python scripts/reproduce_reading.py warning --trace

A trace shows the intermediate steps rather than only the finished text. Here, each row follows one rune from its input alphabet position to its output. The format is CSV (comma-separated values), so you can also open it in a spreadsheet. The first two steps are explained below; expand the CSV sample to inspect the exact exported columns and rows.

Atbash maps index x to 28 − x. The first rune has index 4, so its output index is 24, labeled A. The second has index 21, so its output is 7, labeled W. These are zero-based alphabet indices, not prime values. A two-letter Latin label such as NG still represents one rune.

You only need the input index, output index and Latin label to follow this Atbash example. The remaining fields help when a method crosses page boundaries or skips particular runes:

FieldMeaning
page_rune_ordinalZero-based rune position within the page; resets at each new page.
section_rune_ordinalPosition under the control’s section/boundary rule. It can continue across pages.
input_index, output_indexPositions in the 29-rune alphabet before and after the transformation.
subtracted_valueThe applied Vigenère or prime-minus-one amount. Blank for Atbash, direct reading, or a copied interruption; blank is not a recorded zero.
key_position_before, key_position_afterThe consumed-keystream counter before and after the rune, including the control's starting offset. Equal at a copied interruption. Blank for methods without a keystream.
key_slot_beforeFor Vigenère, the counter before the rune modulo key length. A copied rune leaves this slot unused. Blank for other methods, including the nonrepeating prime stream.
latinThe output rune’s Latin label, before contextual English editing.
copiedWhether this position is listed as an interruption in the control. False does not mean the index changed: direct readings also have false entries.

Non-rune characters are preserved in the literal output but do not get trace rows. For a key-dependent example, run python scripts/reproduce_reading.py welcome --trace and follow keystream positions and interruptions. The specific LP1-10 correction is applied before transformation and trace output; see transcription layers.

Save a reading or trace

Use --output to keep the result as a file. The script checks the reading against its stored control before writing anything, saves UTF-8 text, and refuses to replace an existing file.

python scripts/reproduce_reading.py warning --output warning.txt
python scripts/reproduce_reading.py warning --trace --output warning-trace.csv

The filenames above are created in your terminal’s current folder. You can choose another existing folder; quote the path if it contains spaces. The script does not create missing folders. The text file contains the same page headings and literal reading as the terminal output. The CSV contains only the header and trace rows; the “Saved” confirmation is printed to the terminal, not inserted into the file.

When importing the CSV into a spreadsheet, select UTF-8 and a comma delimiter if asked. Each rune has its own row. A multi-page section such as Welcome keeps the page ID in every row, so the trace can be filtered without losing its page attribution. Keep this original export alongside any spreadsheet you edit.

This option saves a named section, with or without --trace; it does not combine with --list or --check-all. A saved trace documents the known control’s computation, not a new experiment on an unsolved page.

When you are ready to try another method

The warning example needs only Python and the reference-data bundle. Other tasks work on different layers of the manuscript. Reconstructing already-extracted text is different from extracting it from a JPEG yourself, which is why their software requirements differ.

For image-based work, extract the original-images ZIP into the same folder as the reference data. See the bundle instructions for the complete command list.

Check those image files with python scripts/verify_bundle.py ORIGINAL-IMAGES-CONTENTS.json. Each download has a separately named manifest. Prefer these names to the generic CONTENTS.json, which another bundle may replace when extracted into the same folder. Passing the reference-data check does not check images from the image bundle.

Install an optional package only when you need it

You can complete the warning walkthrough, prime-sum checks, concordance, and IoC calculation without installing any Python packages. To redraw the chart, install Matplotlib into the same Python environment that will run the plotting script. To recount image pixels, install Pillow. The package names and Python import names differ for Pillow: its code is imported as PIL.

python -m pip install matplotlib
python scripts/plot_rune_frequencies.py --output my-rune-frequencies.svg

The installation command may download packages; the plotting command reads local files. If you use py or python3 for the scripts, use that same command before -m pip. This avoids installing a package for one Python interpreter and running the script with another.

For a separate project environment, create a local .venv folder and invoke its Python directly. Activation is optional:

Windows PowerShell

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install matplotlib
.\.venv\Scripts\python.exe scripts/plot_rune_frequencies.py --output my-rune-frequencies.svg

macOS / Linux

python3 -m venv .venv
.venv/bin/python -m pip install matplotlib
.venv/bin/python scripts/plot_rune_frequencies.py --output my-rune-frequencies.svg

Keep the environment separate from the preserved evidence files. Record package versions when sharing a generated figure: python -m pip show matplotlib reports the installed version. Visual output can vary across package or font versions even when the underlying numerical counts agree.

When a command fails

  • “Command not found” or “not recognized”: check the Python command first. If it names outguess or gpg, that is a separate executable, not a missing rune dataset.
  • “Can’t open file” for the script: check the terminal’s current folder. Open the extracted folder that contains scripts, rather than its parent folder or the ZIP itself.
  • A missing text/ or data/ file: extract a fresh reference-data bundle and keep its directories together. Moving just the script breaks the relative paths it uses to find its inputs.
  • No module named matplotlib or No module named PIL: install the optional package for the Python interpreter running that particular task. Neither error means the basic reading checks need those packages.
  • “Output already exists”: choose a new output filename or inspect the existing result. Scripts that refuse overwrites do so to preserve earlier output, not because the calculation failed.
  • Boxes instead of runes: the terminal font may lack runic characters. Check the numeric indices and Latin labels, and compare with the browser reader. Missing glyphs alone do not establish bad input bytes.
  • “Output differs” or a hash mismatch: preserve the full error and identify the affected file. Compare with an unchanged copy and the checksums. Do not change the expected output merely to make the check pass.

Keep the result reproducible

Record the repository commit, Python version, command, and output. In a Git checkout, git rev-parse HEAD prints the commit ID. For a ZIP download, retain the archive and its checksum; do not claim a commit ID you have not verified. When you move from a control to a new hypothesis, follow documenting a reproducible attempt. A passing control is a starting point, not evidence that the same method solves another page.

Reproducing rune prime sums provides a read-only command and explicit spelling comparisons.
