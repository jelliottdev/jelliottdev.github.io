Arithmetic keystreams

Define numerical shift sequences, alignment rules and finite searches before comparing candidate readings.

An arithmetic keystream generates a numerical shift for each position. The sequence can come from primes, Fibonacci numbers, a polynomial or another specified rule. A name such as “use primes” leaves several different ciphers possible: the sequence, its starting point and the way it advances all matter.

For a prime p, φ(p) = p − 1. That identity explains the known LP2-56 method; it does not make the totients of consecutive integers the same stream. Likewise, a rune’s assigned prime value or a prime-index operation is a different input from the position counter used here.

Turn the idea into a reproducible rule

A simple subtraction decoder is plaintext[i] = (ciphertext[i] − sequence[i + offset]) mod 29, using rune indices 0–28. Fix the sequence definition, offset range, arithmetic direction and modulus before evaluating results. State whether punctuation consumes a shift, whether the counter resets at words or pages, and whether any rune interrupts it. A copied symbol that pauses the counter differs from a zero shift that advances it; see alignment and interruptions.

If the sequence depends on previous plaintext or ciphertext, include that state explicitly and consult feedback methods. Changing the rule whenever the output stops forming words creates additional choices, not a continuation of the original fixed test.

For a small invented example, take ciphertext indices 10, 20 | 5, where the bar marks a word break. Subtracting prime-minus-one shifts 1, 2, 4 without resetting gives 9, 18 | 1 modulo 29. Resetting the sequence at the word break instead uses 1, 2 | 1 and gives 9, 18 | 4. Both rules agree on the first word and disagree immediately afterward. A short matching opening therefore cannot settle the reset rule.

Count distinct outputs as well as settings

Trying 29 offsets and two signs gives 58 configurations per input under those rules. Some may produce identical outputs. Only residues modulo 29 affect this decoder, so a repeating residue stream can make additional offsets redundant. Similarly, subtracting primes instead of primes minus one changes every output by a constant −1 when alignment is identical. If all constant output shifts are already searched, those variants cover the same set of outputs.

Documented tests and what remains open

The prime-minus-one, ordinary-prime, Fibonacci and consecutive-totient records test declared opening hypotheses with fixed alignment rules. The direct-polynomial record asks a different question: can a polynomial directly generate the observed rune values? Its finite-difference obstruction covers its stated degree range without enumerating coefficient values. A polynomial used as a key mixed with unknown plaintext is outside that result. Read each record’s scope before carrying a negative finding to another variant.

For an extension, freeze the full rule and success criterion, retain all candidates, and test an untouched continuation. Compare the best selected score with the same search on controls, rather than comparing one selected candidate with an ordinary random sample. See null models and all method families.
