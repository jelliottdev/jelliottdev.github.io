The name The Lady of Shalott can refer to Tennyson’s poem, Waterhouse’s painting, or the painting image preserved in a Cicada archive. Those objects have different roles. The archived painting belongs to the 2012 second-chance route; its appearance does not establish Tennyson’s poem as a Liber Primus key or identify the manuscript’s reclining figure.

What does the painting show?

Waterhouse depicts the woman leaving in a boat. Tate draws attention to the woven fabric, the chain she releases, and the candles beside the crucifix; two candles are extinguished. These details connect the painted scene to the poem’s final journey. The painting’s subject and the image file’s hidden contents are separate layers of evidence. Tate’s description.

What role did it play in 2012?

The pinned 2012 walkthrough’s “A Second Chance” section associates NHYLD.jpg with that route. Its stored message contains a second-chance invitation, an image address ending in hkdgl.png, and 22 colon-separated number pairs. The same archive retains hkdgl.png.

The walkthrough identifies that next image with Blake’s The Marriage of Heaven and Hell and reports using Blake’s text for the book code. It does not report using Tennyson’s poem at that step. This is a useful distinction: a painting can carry a message that points to a different author’s book.

Liberpedia has now reproduced the default-key extraction: all 1,079 bytes match the pinned archive’s stored output. GnuPG validates the extracted message against the stored Cicada key in a fresh isolated keyring. The subsequent book-code lookup also reproduces the historical output; its exact counting rules and trace appear below. See files and reproduction below for the exact scope.

Use the pinned repository files for historical inspection. The account warns that the old image-host address could later show unrelated content. A historical URL is therefore not sufficient to identify the bytes used in a reproduction.

What happens in the poem?

In the 1842 version, the Lady weaves in isolation and sees the outside world reflected in a mirror. She turns to look toward Camelot after Lancelot passes; the mirror breaks, and she leaves in a boat. She dies before reaching the inhabited destination. This sequence supports questions about mediated experience, artistic work and the cost of leaving isolation. Those are interpretations of the poem, not decoded instructions from Liber Primus. Read both versions.

The ending changes between versions: the earlier text includes a written message, while the 1842 ending gives Lancelot a response to her arrival. A quotation or book-code proposal must name its version. A line, word or character coordinate cannot safely be moved from one edition to another without checking the actual text.

Is the reclining manuscript figure the Lady?

That identification is not established here. The reclining-figure guide locates the drawings on LP1-14–16 and LP2-22 and records a separate published comparison with Jung’s Red Book. A woman in an earlier puzzle painting does not identify a later manuscript drawing.

A useful comparison would specify the pose, hands, limbs, fabric and surrounding shapes, then show what matches and what differs under a stated reflection or rotation. A shared theme of isolation or inwardness is a literary association; it cannot replace an image comparison. See how source-image comparisons are documented.

How this connects to the rest of the wiki

Blake’s literary connections and the 1033.jpg cover concern different evidence. The cover is part of the earlier 2014 route and contains identified Blake compositions; NHYLD.jpg is a separate 2012 artifact. Neither should be confused with the numbered LP1 title pages.

For proposals using the poem as a key, define the version, selected passage, normalization, target and cipher before testing. An archive entry showing the painting does not mean that every Tennyson-based key has already been tried. A reproducible test belongs in Have we tried it?, with its bounds and outputs.

Download and reproduce the hidden message

Use the original carrier JPEG, not a screenshot, thumbnail or another reproduction of the painting. The raw extracted message and verification manifest are available separately. The manifest records source URLs, byte counts, SHA-256 hashes, the extraction build and signature status.

Extract the reference-data ZIP with its folders intact. It includes the extraction script, manifest and preserved message; place the original JPEG at images/second-chance-2012.jpg. Install OutGuess for your operating system, then run:

python scripts/extract_payload.py second-chance-2012 --outguess outguess --output second-chance-message.bin

The wrapper checks the input hash, extracts using the default key and checks the output hash before saving a new file. It refuses to overwrite an existing output. OutGuess setup and extraction conventions explain the underlying command.

For the signature, install GnuPG and create an empty verify-keyring directory. From the extracted reference bundle, run:

gpg --no-options --homedir verify-keyring --batch --no-auto-key-retrieve --import exports/steganography/cicada-public-key.asc
gpg --no-options --homedir verify-keyring --fingerprint
gpg --no-options --homedir verify-keyring --batch --no-auto-key-retrieve --status-fd 1 --verify exports/steganography/second-chance-2012.outguess.bin

Compare the full fingerprint: 6D854CD7933322A601C3286D181F01E57A35090F. The recorded run returns VALIDSIG for that fingerprint, with the signature dated 11 January 2012. It also reports undefined trust: a valid signature is not a verified real-world identity. No compatibility override was required in the recorded GnuPG 2.5.21 run.

The JPEG checksum answers whether you have these exact image bytes. The signature checks the signed message extracted from them. Neither operation reproduces the subsequent book cipher. See signature validity, identity and whole-file checksums.

Reproduce the Blake book code

The next image is identified in the historical account as a detail of plate 4 of Blake’s The Marriage of Heaven and Hell, headed “The voice of the Devil”. The 2021 reproduction by Connor Tumbleson supplies a line-preserving transcription. This reproduction uses those exact downloaded bytes, with a recorded checksum; it does not silently substitute a reflowed modern edition.

Inspect the plate image, download the attributed transcription, or download the full lookup trace. Blake’s underlying text is public domain. The transcription retains its source comment.

  1. Remove the two heading lines, blank lines and the final source comment. Eighteen body lines remain.
  2. Trim indentation at the ends of each line. Keep spaces inside a line, punctuation, numbered paragraphs and the line-ending hyphen in princi-.
  3. Read each signed-message pair as line:character, counting both from 1. A character is not a word or a letter-only position.
  4. Concatenate the selected characters in message order. No anagramming, skipped coordinates or spelling repairs are needed.

For example, line 4 is ples Viz: a Body & a Soul.. Positions 7 and 8 give i and z; position 26 gives the period. Removing spaces would change the coordinate system and fail to reproduce this result.

It does not establish that every edition has identical line breaks, nor does it solve a numbered Liber Primus page.

From the reference-data ZIP, run the following command. It checks the input hashes and prints the 18 source lines, all 22 lookups and the assembled result as JSON. It makes no network requests.

python scripts/reproduce_second_chance.py

This is a worked example of why a book-code proposal needs an exact edition, passage and counting rule. See search space and bounds before extending the method to other texts.
