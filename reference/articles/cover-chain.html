The cover payload chain

The cover, warning, and chapter title combine into a signed message and a transposition.

Three inputs

LP1-00, Liber Primus, LP1-01, the warning, and LP1-02, Chapter 1 — Intus carry OutGuess payloads. Extract and verify them. Their 1,982-digit bodies decode to three 991-byte streams.

XOR corresponding bytes

What XOR means, with a worked byte example.

XOR produces a 0 bit when input bits agree and 1 when they differ. Compute result[i] = A[i] XOR B[i] XOR C[i] on decoded bytes, not on hexadecimal text characters. For example, 0x0f XOR 0x33 = 0x3c.

python scripts/reproduce_cover_chain.py
python scripts/reproduce_cover_chain.py --output combined.asc

The script checks input and output hashes and refuses to overwrite files. Its 991-byte result is another signed message, requiring its own signature check.

Read the columns

Remove spaces from the first two ciphertext lines and arrange the 70 characters in five rows of fourteen:

IDGTKUMLOOARWO
ERTHISUTETLHUT
IATSLLOUIMNITE
LNJ7TFYVOIUAUS
NOCO5JI4MEODZZ

Within each row, take columns in zero-based order 2, 8, 9, 1, 12, 13, 11, 4, 5, 7, 3, 0, 6, 10. Concatenate the five reordered rows from top to bottom. This transposition gives:

GOODWORKULTIMATETRUTHISTHEULTIMATEILLUSIONJOINUSATFV7LYUCMEOZZD5J4ONIO

Preserve the literal ending

The exact output ends in ONIO. The historical walkthrough restores a final N to render fv7lyucmeozzd5j4.onion. That character is an interpretation, not a permutation output. This is a historical address, not a claim of current reachability.

The supplied permutation reproduces the known result. It does not show that a unique ordering can be inferred without clues or applied to another page.
