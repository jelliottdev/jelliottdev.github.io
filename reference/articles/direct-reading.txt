Direct reading

When rune labels already form a readable sequence.

Identity transformation
Direct reading uses p = c: label each rune without changing its index. Distinguish the literal labels from contextual English.
How to replicate
python scripts/reproduce_reading.py some-wisdom
python scripts/reproduce_reading.py loss-of-divinity
python scripts/reproduce_reading.py instruction
python scripts/reproduce_reading.py lp2-57
These cover LP1-05, LP1-10–13, LP1-16 and LP2-57. The loss-of-divinity control includes the documented correction.
Readable does not mean exhausted
Several direct-reading pages also have OutGuess payloads. Visual details and numerical patterns need their own evidence.
