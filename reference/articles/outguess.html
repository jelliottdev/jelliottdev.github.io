OutGuess extraction

Recover hidden bytes from the original JPEG before interpreting them.

Steganography, not a rune cipher

OutGuess retrieves data hidden in an image carrier. Resizing, resaving, screenshotting or recompressing a JPEG can change its bytes. Use the original JPEG, not a thumbnail.

How to replicate

Install or build OutGuess for your operating system. No executable is bundled here. From the repository root, use an executable on PATH or supply its path:

python scripts/extract_payload.py lp1-00 --outguess outguess --output cover.bin

The wrapper checks the image hash, retrieves the default-key payload, and checks its expected hash before writing a new file. It refuses to overwrite a destination. The underlying operation is:

outguess -r -k "Default key" images/lp1-00.jpg cover.bin

The cover’s full extraction is 2,899 bytes. Checksums and the exact verified build are in the manifest. Compare output bytes, not merely a success message.

Keep the layers separate

Preserve the full extraction. The exported signed block supports PGP verification; the body is a separate derivative. On the cover, that body is hexadecimal. Follow the three-image chain to interpret it.
