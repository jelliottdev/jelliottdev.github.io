Search the known readings: a concordance

Find words and phrases across nine contextual readings, with reproducible counts, surrounding text, and source hashes.

A concordance locates a word or phrase and shows its surrounding text. This tool searches the nine contextual known-reading sections in Liberpedia. It is useful for comparing terms such as circumference, divinity, self, and instar without relying on memory or repeatedly opening every section.

Run a lookup

Extract the reference-data ZIP, keep its folders together, and run these commands from the extracted directory with Python 3. No extra Python package, network connection, or AI service is needed.

python scripts/reading_concordance.py circumference
python scripts/reading_concordance.py circumference --prefix
python scripts/reading_concordance.py "voice inside your head"
python scripts/reading_concordance.py instar --context 15

Exact search matches whole words or contiguous word sequences, ignoring case and most punctuation. Prefix search accepts one word and matches words that begin with it. Thus circumference --prefix includes the plural, while an exact query does not. Internal apostrophes are retained, so DON'T stays one word; a typographic apostrophe is normalized to the same character.

Read the result

Each hit gives a section ID, its page range, a one-based contextual word position, and the matched text in brackets. The surrounding text is limited by --context, which accepts 0–50 words on each side.

loss-of-divinity (lp1-10, lp1-11, lp1-12, lp1-13), word 6
THE LOSS OF DIVINITY THE [CIRCUMFERENCE] PRACTICES THREE BEHAVIORS ...

This shortened example illustrates the output; the command prints its actual context rather than an ellipsis. A section range does not identify the exact page holding the word. Open the complete reading to compare its literal page outputs and original images.

What is being searched?

	Included	Outside this search
	One contextual English reading for each of nine sections	Unsolved ciphertext, artwork, and OutGuess messages
	Whole-word and contiguous-phrase matches	Synonyms, semantic similarity, and automatic stemming
	Contextual word positions	Rune offsets, literal prime sums, or exact image coordinates

The tool searches each section once. A four-page section is not counted four times. It also does not join the end of one section to the beginning of another when matching a phrase. A zero result means the requested token sequence was not found in this contextual compilation; it says nothing about the unsolved pages.

Contextual English expands or interprets some literal rune labels. A count in this representation is therefore not automatically a count of literal rune sequences. Use rune indices and prime values when working with the actual encoded symbols.

Save a machine-readable result

python scripts/reading_concordance.py circumference --prefix --json
python scripts/reading_concordance.py circumference --prefix --json --output circumference-concordance.json
python scripts/reading_concordance.py circumference --prefix --output circumference-concordance.txt

The JSON output includes the query, matching mode, tokenization rule, source-file SHA-256, and every hit. Add --output to save the result as a UTF-8 file. The command refuses to overwrite an existing file; choose a new name for a later run. A relative filename is saved in your current working directory, so run these commands from the extracted bundle or repository directory.

Use --json for structured results, including exact source excerpts and character positions. Omit it for the readable text report. The filename extension does not select the format: --json does. Without --output, the result is printed in the terminal. A lookup with no matches still produces a valid report with zero occurrences.

The hash identifies the exact contextual compilation searched. It is not a signature or evidence that the contextual rendering is an original manuscript file. Read the checksum guide for that distinction.

Keep the original wording when comparing passages

Search matching ignores case and most punctuation, but those details can matter when discussing a passage. Each JSON hit therefore also includes matched_source, the matched words with their original capitalization, punctuation and whitespace, and source_excerpt, the surrounding words preserved in the same way. “Original” here means the stored contextual reading, not the manuscript’s rune stream.

For example, searching don't stop can match Don’t, STOP. The normalized match is DON'T STOP, while matched_source retains Don’t, STOP. This lets you find a phrase flexibly without silently rewriting it when you inspect the result.

The fields source_start and source_end locate that match inside the section’s reading string. They count Unicode characters from zero, with the end excluded: in Python, reading[source_start:source_end] recovers matched_source. They are not UTF-8 byte offsets or positions on the manuscript image. The excerpt starts at the first included word and ends at the last included word; punctuation between those words is preserved, but punctuation outside those boundaries is not included.

Check the implementation

python scripts/test_reading_concordance.py

The checks cover the three circumference passages, singular-versus-prefix matching, phrase boundaries between sections, apostrophes, and duplicate section rejection. The script and tests are included in the reference-data bundle.
