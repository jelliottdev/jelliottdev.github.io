Acrostics and boundary-letter extraction

Select initial, final or regularly indexed symbols from defined units.

An acrostic extracts initial symbols from defined units; a telestich extracts final symbols. The units might be words, lines, paragraphs or pages. Other positional extraction methods select the nth symbol or alternate between boundaries.

Major variants

Variants include first and last runes, initials after transliteration, fixed interior positions and extraction driven by a separate number sequence. These can differ when one rune represents several Latin letters.

Follow one rule across every unit

Use three invented units: [2, 8, 4], [1, 7] and [6, 0, 5]. These are symbol indices, not a manuscript reading.

	Declared extraction	Output	Choices involved
	First symbol of every unit	2, 1, 6	One fixed rule
	Last symbol of every unit	4, 7, 5	A second fixed rule
	First, last, first	2, 7, 6	A specified alternating rule
	Choose first or last separately for each unit	Eight candidate outputs	2³ endpoint settings
	Choose any symbol separately from each unit	Eighteen candidate outputs	3 × 2 × 3 position settings

An alternating rule fixed in advance is one candidate. Discovering the same pattern while trying endpoint combinations belongs to the larger search. With n units, independent first-or-last choices give 2^n settings; arbitrary positions give the product of the unit lengths. Repeated symbols can make different settings produce identical outputs.

Count source symbols before transliterating

Suppose a unit contains two source symbols transliterated as TH and A. Its first source symbol is the whole TH symbol; its first Latin character is only T. Selecting after transliteration can therefore split a symbol that selecting before transliteration keeps intact. Record both the selected source position and its displayed transliteration. See transcription checking.

Short units also need a rule. Selecting the third symbol from a two-symbol unit is undefined unless the method specifies a policy such as skipping, wrapping or rejecting that candidate. These policies produce different outputs and different search spaces. Likewise, a word continued across a printed line or page boundary is not automatically two separate words.

Choose controls for the claim being made

If the claim is that the extracted symbols form an unusually coherent sequence, shuffling the extracted symbols tests order while preserving their counts. If the claim is that word beginnings are special, shuffling the already extracted output cannot test that claim: the endpoints have already been selected. A comparison could instead sample one position from each unchanged unit, with the sampling rule declared in advance. That asks a different question and has its own assumptions.

When a search tries first symbols, last symbols, multiple unit definitions, reversals and several languages, each control must receive that same search before its best score is compared with the observed best score. Report the full extraction, including unconvincing continuations, rather than only a short matching word. See null models and automatic search and candidate scoring.

What a test must specify

Define units and their boundaries, source layer, heading treatment, indexing origin and behavior for short units. Specify whether positions count runes, transliteration characters or bytes. Fix any alternating or repeating selection pattern before viewing the output.

How to evaluate a result

Retain a trace from each selected symbol to its source unit. Compare the complete extraction with the same procedure on controls. Do not remove inconvenient units or insert spaces only after a phrase appears without recording those extra choices.

Documented experiments

Two replayed searches of already-decoded text tried 3,508 positional selections and 48 line- or word-edge readings. None crossed the final score thresholds, but neither did any of the four planted messages. Those results therefore do not show that the tested hiding places are empty. The searches did not use unsolved LP2 ciphertext; the line/word search used five decoded sections spanning ten LP1 images in source-specific order. The source audit records the exact inputs and limits.

A separate LP2 line-initial study found that first runes looked unusual against random manuscript positions, but ordinary when shuffled text was wrapped into lines using estimated rune widths. Its six fixed English-reading searches also found no message. This tests those readings and that approximate layout model, rather than every possible acrostic.
