Visual observations

Detached wing above the text: A long wing-shaped drawing sits above the opening text. It has a dark outer boundary and a network of internal lines enclosing areas. No complete insect body is attached to this drawing. Enlarged red opening rune: A large red rune stands at the left of the first three text rows. The first row also begins with smaller red runes before the text changes to black. Color and size are separate features to preserve in any proposed extraction.
