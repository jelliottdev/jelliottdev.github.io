# Wulfic legacy optimizer dependency audit (internal)

Pinned source: `Wulfic/Cicada3301-Liber_Primus` at `bf89d3d13aad2b8f2c95ab195cf1b092f250775c`. This is an input and provenance audit, not a replay or a decryption result. I inspected Git objects with `git ls-tree` and `git show`, because the local checkout is sparse. `research/prior_work.py` returned no exact published source-path replay for the representative GPU, anchored, P02, P24 and P25 optimizer scripts; a generic method resemblance is not coverage.

## Trust boundary

The source's `data/archive/hillclimbers/20260529/README.md` (blob `f4f5e0b2f13d380aae7d366cd7ebd09cad526bf2`) says **not to use the archived outputs as evidence**. It says old `page_N/runes.txt` files held misaligned LP2 pages and many results came from optimizers. The `MOVES.txt` manifest (blob `f0abaf371762b4a2b913823773387906fb147ca4`) distinguishes `T` entries moved with Git from `U` entries that were untracked in the original owner's working copy. The latter are not in this pinned Git tree. A moved historical result is available as a byte artifact, but its label, target and score are not thereby validated.

The mapping problem is observable from Git bytes: current `pages/page_25/runes.txt` has 255 Runic characters; `0f89de5:pages/page_25/runes.txt` has 1,729. Their starts agree, but their lengths differ radically. That historical file is not an acceptable substitute for today's corrected page 25, nor is the archived result a fresh computation on today's page. The current 75-page mapping was independently audited in `research/source-intake/wulfic-legacy-page-map-2026-10-23.json`.
In that mapping, current image ordinal `page_25` is **LP2-08** (255 runes); LP2-25 is current ordinal `page_42` (273 runes). Any new P25 experiment must say which target it means rather than silently transferring a source filename into an LP2 page label.

## Replay decision

No historical optimizer failure is established by this audit. The largest chains lack a stop rule or public selected checkpoints, and the committed archived keys/candidates are explicitly invalidated by their own source documentation. The finite P25 first-stage sweep and the P02 fixed-seed decoders are candidates for **new** controlled variants, not exact receipt replays. If one is taken next, freeze the corrected manuscript target, recovered corpus blob, original scoring code, whole-selection baseline and planted positive control before reading its score; retain original source bounds instead of shortening them for convenience.
