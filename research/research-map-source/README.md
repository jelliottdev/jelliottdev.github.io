# Pinned draft map sources

These JSON files preserve the selected solving and research/analytics hierarchies from the user-provided `Liberpedia-handoff/prototype/ideas-graph` design handoff. They are draft exploration categories, not evidence of equivalent experiments. `provenance.json` records each original relative path and SHA-256 and identifies the pinned 314-record registry commit and hash.

`scripts/build_research_map.py` verifies these bytes, retains the exact tree topology, and reconciles the classification references with actual published records. Current record text comes from `data/experiments.json`. Records added after the pinned snapshot receive no invented classification. See `research/source-intake/research-map-migration-2026-10-24/INTEGRATION.md` for the API and reconciliation details.
