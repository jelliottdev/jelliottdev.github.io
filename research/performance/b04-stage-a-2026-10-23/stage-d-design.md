# Stage D execution design (not run)

The pinned `sweep.stage_d` takes `top50` from **each** completed A, B, and C source summary in that order, sorts all rows by descending score, and keeps the first occurrence of each `(seed_hex, gen, red, sign, atbash, dir, offset)` tuple. At most 150 unique tuples survive; the source's `>=300` break is unreachable with these three inputs. The tuple list must be frozen and hashed only after B and C are complete. A source-compatible tie order matters, so do not pre-sort by any additional field.

For each tuple, the source makes a key of `len(ciphertext) + offset + 512`, reverses it for `dir=rev`, chooses the original or Atbash ciphertext, then calls `skipdecode.beam_decode` with beam width 400 and max skip 3. It runs the same tuple first against full LP2-00 and then the 12,956-rune joined unsolved stream. The fixed score bar is −5.5. Preserve the original scorer and its zero-extension behavior; do not substitute a longer key silently.

Proposed wrapper: store one atomic, content-hashed result per `(segment, tuple_index)` plus a manifest binding the A/B/C summary hashes, ordered tuple list, source revision/file hashes, ciphertext hashes, score bar, beam settings and native key length rule. Resume only complete verified cells. Merge in source tuple order, then apply the source's descending-score sort and summary fields. Independently compare several short synthetic configurations and the first few original cells against direct `sweep.stage_d` logic before a full escalation.

Key-padding audit: pass a list subclass that returns the same values and records the maximum key index read and whether any read crosses the native key length. Its `+ [0] * ...` operation must return another tracked list sharing counters, so the decoder's existing padding branch runs unchanged. Verify instrumented and ordinary decodes have identical score, transcript prefix, and final pointer on a small fixed set. Record the padding-read count per cell; label the source result conditional on this key-material rule if padding is actually used. Do not repair it in the historical replay.

Stage D is held until B/C summaries and the ordered tuple list are frozen. A head-screen miss alone does not prove the later full-stream decoder cannot score above the threshold; the source's early-gate claim is only conditional on its screening rule.
